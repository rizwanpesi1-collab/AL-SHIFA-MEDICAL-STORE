Ready. Load a website or upload media.

1. WEBSITE SOURCES

Some websites block iframe embedding. If a site refuses to open, normal HTML cannot force it to load inside this screen.

2. VIDEO AND LAYOUT

Transparent PNG layouts work best for overlays.

3. CROP AND ZOOM

Drag the yellow box to move it. Drag its corner to resize. Applying the crop zooms the visible website frame; it does not extract the website's internal pixels.

4. WHITE BACKGROUND REMOVER

This tool removes white pixels from the uploaded image/layout. It cannot directly read pixels inside a protected live website.
